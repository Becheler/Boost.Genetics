🧬 Boost.Genetics

High-performance C++17 library for genomic data processing

Features

  • ⚡ Ultra-fast VCF parsing - 60% faster than bcftools
  • 🔄 Parallel processing - Near-linear scaling up to 4 cores
  • 💾 Zero-copy design - Minimal memory allocations
  • 🎯 Modern C++17 - Clean, type-safe API
  • 📦 Header-only - Easy integration

Quick Start

// Sequential parsing
vcf::reader reader("variants.vcf");
for (const auto& record : reader) {
    std::cout << record.chrom() << ":" << record.pos() << std::endl;
}

// Parallel parsing (4 threads)
vcf::parallel_reader parallel("variants.vcf", 4);
auto records = parallel.read_all_unordered();
std::cout << "Parsed " << records.size() << " records" << std::endl;
